# HeritageX
React + Vite + Tailwind. Run `npm install` then `npm run dev`. Deploy on Vercel (vercel.json handles SPA routing).

- Set the demo video in `src/utils/config.js` (`DEMO_URL`).
- Media goes in `public/videos`, `public/audio`, `public/images/<folder>` using the filenames in the PRD.
- Missing media shows a placeholder instead of breaking the page.

Built: Home, AR Studio, Dhokra (landing + 9 step routes), Explore (4 heritages with Explore / Learn / Try).
Planned: Oral Heritage (+ audio, transcript, translation, knowledge graph), Contribute, About.
